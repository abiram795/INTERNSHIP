# Task Management Application

A modern and responsive Task Management Web Application designed to help users organize daily activities, manage tasks efficiently, track progress, and improve productivity through an intuitive dashboard.

## Features

- User Login and Registration
- Interactive Dashboard
- Create, Edit, and Delete Tasks
- Task Status Management
- Priority Management (Low, Medium, High)
- Task Search and Filtering
- Calendar View
- Productivity Statistics
- Notifications
- Dark and Light Mode
- Responsive Design
- LocalStorage Data Persistence

## Tech Stack

- React.js
- Vite
- JavaScript
- Tailwind CSS
- Lucide React
- LocalStorage

## Application Highlights

- Clean and modern SaaS-inspired interface.
- Dynamic dashboard with real-time UI updates.
- Reusable React components.
- Persistent task management using browser LocalStorage.
- Mobile-friendly and responsive layouts.

## Getting Started

1. Clone the repository.
2. Install dependencies using `npm install`.
3. Start the development server using `npm run dev`.
4. Open the local development URL in your browser.

## Purpose

This project demonstrates frontend development skills, React component architecture, state management, CRUD operations, responsive UI design, and browser-based data persistence.
